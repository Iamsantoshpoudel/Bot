Features

Built to run unattended.

Every control here exists because something eventually goes wrong at 2am when no one's watching. Dex's Music is built to handle that without you.

Auto-join, auto-leave

Connects a moment after the first person arrives, and leaves quietly once the channel's empty. No one has to remember to start it.

Shuffles without repeats

Every reshuffle checks against the last track played, so the same song never lands twice in a row.

Streams, never downloads

Tracks are transcoded on the fly straight from storage. The file never touches a disk anywhere along the way.

Guarded by default

Only members in the voice channel — or roles you choose — can control playback. Everyone else can still check what's on.

Recovers on its own

A dropped connection or a bad file gets retried automatically. If something's really broken, it restarts clean rather than getting stuck.

Your library, your rules

Music lives in your own private storage bucket. Nothing is ever made public — the bot only ever hands out short-lived links to itself.

How it works

Add a track, it plays. That's it.

No admin panel, no bulk uploader to wrangle. Setup is one folder.

01

Drop a file into your library

Upload an mp3, wav, ogg, m4a, flac, aac, opus, or webm file. Name it "Artist - Title" if you want it labeled automatically.

02

Dex's Music finds it on its own

The library is rescanned on a timer. New files are picked up and added to rotation — nothing to trigger by hand.

03

It plays when people show up

The moment someone joins the voice channel, Dex's Music connects and starts streaming from the shuffled queue.

FAQ

Before you ask

—

Where does the music actually come from?

Whatever's in your own private storage bucket. Dex's Music doesn't ship with a library or pull from any external streaming service.

—

Can it play in more than one channel?

Each server has one configured voice channel by design, to keep behavior predictable. Multi-channel support is a documented extension point if you self-host.

—

What happens if it crashes?

It doesn't, quietly. Failures are logged, retried up to three times, and if that's not enough the process restarts itself cleanly instead of hanging.
